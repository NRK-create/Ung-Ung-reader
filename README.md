# อุ๋งอุ๋งอ่านนิทาน (เวอร์ชันเกม)

แอปเว็บ (PWA) ให้เด็กอ่านนิทานออกเสียง มีสมาชิก คะแนน เช็กอินรายวัน และตารางอันดับ
ใช้ได้ทันทีหลังอัปโหลดขึ้น GitHub Pages ในโหมดทดลอง และเปิดระบบสมาชิกจริงได้โดยตั้งค่า Firebase (ฟรี)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | หน้าตาและตัวเกม |
| `backend.js` | สมัคร/เข้าสู่ระบบ/ลืมรหัสผ่าน/เก็บคะแนน/อันดับ (Firebase หรือโหมดทดลอง) |
| `firebase-config.js` | **ที่เดียวที่ต้องแก้** เพื่อเปิดระบบจริง |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล วางใน Firebase |
| `stories/easy`, `stories/challenge`, `stories/hard` | นิทาน 334 / 333 / 333 เรื่อง (รวม 1,000) |
| `sw.js`, `manifest.webmanifest`, `icons/` | ติดตั้งเป็นแอปและใช้ตอนไม่มีเน็ต |

เพิ่ม/แก้นิทาน: เปิด `stories/<หมวด>/stories.js` แต่ละเรื่องคือ `["ชื่อเรื่อง","คำ|คำ|คำ/คำ|คำ|คำ"]`
`|` คั่นคำ `/` คั่นประโยค เรียงจากง่ายไปยากในแต่ละหมวด (ผู้เล่นอ่านตามลำดับ)
ถ้าเพิ่มเรื่องใหม่ต่อท้าย ต้องแก้ตัวเลขเพดานใน `firestore.rules` (s1, s2, s3 และความยาว be/bc/bh) ให้ตรงด้วย

## กติกาเกม

- คะแนนเช็กอิน วันที่ 1–10 = +5, +5, +10, +10, +30, +5, +5, +10, +10, +50 แล้ววนกลับวันที่ 1 ไม่มีวันหมด
  เช็กอินอัตโนมัติเมื่อเปิดแอปครั้งแรกของวัน ถ้าขาดไปหลายวัน วันนับต่อจากเดิม ไม่ถูกรีเซ็ต
- คะแนนอ่านต่อเรื่อง = คะแนนเต็มของหมวด × สัดส่วนคำที่อ่านถูกตั้งแต่ครั้งแรก
  (ง่ายเต็ม 10, ท้าทายเต็ม 15, ศัพท์ยากเต็ม 20) ต้องถูกอย่างน้อย 40% จึงถือว่าผ่าน
- เรื่องใหม่ได้วันละ 5 เรื่อง **ต่อหมวด** เรื่องเก่าอ่านซ้ำได้ไม่จำกัด และเพิ่มคะแนนเฉพาะส่วนที่สูงกว่าเดิม
- ไม่ผ่านติดกัน 3 ครั้งในเรื่องใหม่ ปิดหมวดนั้นจนถึงวันถัดไป (หมวดอื่นและการอ่านซ้ำยังเล่นได้)
- ปรับค่าได้ที่ต้นส่วน "เกม" ใน `app.js`: `LOGIN_PTS`, `NEW_PER_DAY`, `STRIKE_LIMIT`, `PASS_ACC`, และ `max` ของแต่ละหมวด
- เบราว์เซอร์ที่ฟังเสียงไม่ได้ จะเป็นโหมดฝึก ไม่มีคะแนน นิทานที่เพิ่มเองก็ไม่มีคะแนน

## ตั้งค่า Firebase (ครั้งเดียว ประมาณ 10 นาที)

1. เข้า https://console.firebase.google.com แล้วกด **Add project** ตั้งชื่ออะไรก็ได้ (ปิด Google Analytics ได้)
2. เมนู **Build → Authentication → Get started → Sign-in method** เปิด **Email/Password**
3. เมนู **Build → Firestore Database → Create database** เลือกโหมด production และเลือกภูมิภาคใกล้ไทย (เช่น asia-southeast1)
4. แท็บ **Rules** ลบของเดิมแล้ววางเนื้อหาจากไฟล์ `firestore.rules` กด **Publish**
5. **Project settings (รูปเฟือง) → General → Your apps → Web (</>)** ลงทะเบียนแอปเว็บ แล้วคัดลอก `apiKey` และ `projectId`
6. เปิดไฟล์ `firebase-config.js` ใส่ค่าทั้งสอง แล้วอัปโหลดขึ้น GitHub ทับของเดิม
7. Authentication → **Settings → Authorized domains** เพิ่ม `ชื่อผู้ใช้.github.io` (ถ้ายังไม่มี)
8. อีเมลรีเซ็ตรหัสผ่าน: Authentication → **Templates → Password reset** แก้ภาษาเป็นไทยและชื่อผู้ส่งได้ (Edit → เลือกภาษา)

`apiKey` ของ Firebase เป็นค่าสาธารณะ ใส่ในไฟล์เว็บได้ ความปลอดภัยอยู่ที่ `firestore.rules`
ฟรีเพียงพอสำหรับผู้เล่นหลักร้อยถึงหลักพันคน (โควตาฟรีของ Firestore ประมาณ 50,000 อ่าน / 20,000 เขียนต่อวัน
และแอปเขียนไม่ถี่ โดยเขียนหลังอ่านจบเรื่องหรือเช็กอิน และหน้าอันดับโหลดครั้งละ 50 รายการ)

## อัปเดตแอปที่ติดตั้งแล้ว

แอปจะดึงไฟล์ใหม่เองเมื่อมีอินเทอร์เน็ต หลังอัปโหลดเวอร์ชันใหม่ให้เปิดแอปสองครั้ง (ครั้งแรกโหลดไฟล์ใหม่ ครั้งที่สองใช้ไฟล์ใหม่)

## ข้อควรรู้

- **คะแนนเชื่อใจเครื่องของผู้เล่น** แอปเว็บไม่มีเซิร์ฟเวอร์ตรวจ จึงมีแค่กฎกันเลขเกินเพดาน/ลดคะแนน/แก้ของคนอื่น
  แต่คนที่เปิดเครื่องมือนักพัฒนาเบราว์เซอร์ยังโกงคะแนนในเพดานได้ และการเลื่อนนาฬิกาเครื่องไปข้างหน้าทำให้ได้โควตา/เช็กอินวันใหม่ก่อนเวลา
  ถ้าจะแข่งจริงจังหรือมีรางวัล ควรย้ายการตรวจคะแนนไปไว้ฝั่งเซิร์ฟเวอร์ (Cloud Functions)
- **ข้อมูลเด็ก** ชื่อเล่นแสดงในอันดับให้ทุกคนที่ล็อกอินเห็น ควรแนะนำให้ใช้ชื่อเล่น ไม่ใช้ชื่อจริง/นามสกุล/โรงเรียน
  อีเมลเป็นของผู้ปกครองและไม่แสดงในอันดับ ควรมีหน้านโยบายความเป็นส่วนตัวก่อนเปิดให้คนทั่วไปใช้ และก่อนส่ง Play Store
  (หมวด Families / แอปสำหรับเด็ก มีข้อกำหนดเรื่องข้อมูลเด็กและการลบบัญชี แอปมีปุ่ม "ลบบัญชีและข้อมูลทั้งหมด" ในหน้าตั้งค่าแล้ว)
- **นิทานที่เพิ่มเอง** (วางข้อความ/ถ่ายรูป) เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ขึ้นระบบ ไม่มีคะแนน
- **โหมดทดลอง** (ยังไม่ใส่ Firebase): บัญชีและคะแนนอยู่ในเครื่องนี้ ไม่ส่งอีเมลจริง และหน้าอันดับมีผู้เล่นตัวอย่างให้ดู
